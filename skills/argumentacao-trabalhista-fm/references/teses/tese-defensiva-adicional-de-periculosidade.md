# Tese defensiva — Adicional de periculosidade

> Catálogo de Teses por Verba (polo reclamada), item 5


**Teses defensivas:**

| Tese | Fundamento | Como argumentar |
|---|---|---|
| Atividade não prevista na NR-16 | — | Sem enquadramento, não há periculosidade |
| Exposição eventual / acessória | Súmula 364, I TST | Tempo extremamente reduzido + acesso eventual afastam adicional |
| Base de cálculo = salário base (não remuneração) | Súmula 191 TST | Calcular só sobre salário base (eletricitário pré-Lei 12.740/12 tem regra própria) |
| Periculosidade absorvida por insalubridade | Art. 193, §2º CLT | Não cumula |
| Pagamento já realizado | — | Apresentar contracheques |
| Laudo pericial impreciso | Art. 195 CLT | Impugnar |
| Motociclista — só após Lei 12.997/14 | Art. 193, §4º CLT | Antes da lei, não havia previsão |
