# Tese defensiva — Salário in natura / utilidades

> Catálogo de Teses por Verba (polo reclamada), item 26


**Teses defensivas:**

- Utilidade fornecida para o trabalho (instrumento) não integra salário — art. 458 CLT
- Vale-refeição via PAT — não integra (Súmula 241 TST aplicada com ressalvas)
- Plano de saúde — Súmula 367, II TST: não integra
- Veículo, celular, notebook fornecidos como ferramenta — não integram
- Habitação para o trabalho — discutir, depende do uso
